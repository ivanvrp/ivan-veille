## 🔥 Top 3 (à actionner cette semaine)

### 1. [Claude Code Week 37 — `claude plugin eval` shippe](https://code.claude.com/docs/en/whats-new/2026-w37)
- 📅 7-11 sept. 2026 (J-4 à J-8) · 📺 code.claude.com officiel · 🏷 Claude updates
- 💡 **TL;DR** : `claude plugin eval` score chaque cas de test avec et sans le plugin pour mesurer sa contribution réelle → livrables JSON + `report.html`. `claude plugin eval init` génère automatiquement les cas de test en mode interactif.
- ⭐ **Pourquoi Ivan** : Si tu construis des plugins Claude Code pour automatiser tes workflows TT/PURESOLE (hooks Shopify pré-push, checklist créa pub, formatage commit e-com), tu peux maintenant prouver chiffres à l'appui si ton plugin améliore vraiment les réponses de Claude — et détecter les régressions avant de les déployer.
- 🎯 **Micro-action ≤15min** : `cd ton-plugin && claude plugin eval init` → Claude propose et écrit les cas de test ; quitte la session puis lance `claude plugin eval .` pour voir le tableau de scores avec et sans.

### 2. [Shopify — WhatsApp consent au checkout (officiel, 10 sept.)](https://changelog.shopify.com/posts/collect-whatsapp-marketing-consent-at-checkout)
- 📅 10 sept. 2026 (J-5) · 📺 Shopify Changelog officiel · 🏷 Shopify / CRO
- 💡 **TL;DR** : Les marchands peuvent maintenant collecter l'opt-in WhatsApp directement à la commande (Settings → Checkout → Marketing opt-in → WhatsApp), alimentant la liste subscriber sans aucune friction supplémentaire.
- ⭐ **Pourquoi Ivan** : Canal CRM gratuit (pas de CPM à payer) pour relancer les acheteurs TT/PURESOLE — taux d'ouverture WhatsApp ×3 à ×5 vs email. Particulièrement fort pour PURESOLE dropship où le SAV et les upsells post-achat font toute la marge.
- 🎯 **Micro-action ≤15min** : Settings → Checkout → Marketing opt-in → activer WhatsApp + choisir le message de bienvenue par défaut. Vérifier que Klaviyo ou ta solution CRM est connecté au Shopify WhatsApp channel.

### 3. [Claude Code 14 sept. — fast mode Remote + allowed_domains par-commande](https://code.claude.com/docs/en/changelog)
- 📅 14 sept. 2026 (J-1) · 📺 code.claude.com changelog officiel · 🏷 Claude updates
- 💡 **TL;DR** : 4 ajouts clés : (1) fast mode disponible dans les sessions Remote cloud/self-hosted, (2) allowed_domains par commande Bash/Monitor en auto mode — les domaines autorisés pour UNE commande, pas toute la session, (3) `omitClaudeMd` dans le frontmatter agent pour lancer des sous-agents sans polluer leurs instructions avec tes CLAUDE.md locaux, (4) archivage auto des sessions VSCode inactives (14j par défaut).
- ⭐ **Pourquoi Ivan** : `omitClaudeMd` est la killer feature pour lancer des agents spécialisés propres dans les automations TT (ex. un agent Shopify sans que ton CLAUDE.md global ne le perturbe). allowed_domains par commande = moins de prompts de permission dans les pipelines cron veille.
- 🎯 **Micro-action ≤15min** : Dans le frontmatter d'un de tes agents plugins : ajouter `omitClaudeMd: true` + tester que l'agent ne charge plus tes instructions globales.

Arcads = talking-head UGC natif (avatar qui parle produit, parfait Meta/TikTok DTC). Higgsfield = cinématique visuel pour hero campaign brand. Si le budget créa est limité : Arcads en priorité pour les ads performance PURESOLE. → *1 campagne Arcads talking-head à tester vs 1 créa studio classique*
