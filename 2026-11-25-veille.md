- 💡 **TL;DR** : Le memory server en mode Streamable HTTP ne libérait pas les lock files à l'arrêt → corruptions de données silencieuses. Fix : exit hook enregistré sur les 2 paths (stdio + HTTP). Un 2e SIGINT/SIGTERM exit maintenant immédiatement.
