### 1. [Claude Code 2.1.237+2.1.238 — Mode "Concise" + release stabilité majeure](https://code.claude.com/docs/en/changelog)
- 📅 Hier (20 août 2026) · 📺 Anthropic officiel (Claude Code changelog) · 🏷 Axe 2 — Claude
- 💡 **TL;DR** : 2 releases en 24h — v2.1.237 ajoute le style de sortie "Concise" (résultats d'abord, zéro préambule ni narration) ; v2.1.238 corrige 25 bugs dont la fuite mémoire en session longue, la désynchronisation Remote Control cross-devices, et le prompt caching via LLM gateway. Nouveau paramètre `keybindingFlavor: readline` pour raccourcis Bash (Ctrl+W = supprime jusqu'à l'espace).
- ⭐ **Pourquoi Ivan** : Claude Code est l'outil central de la veille-360 et des sessions e-com coding. Le mode Concise réduit le bruit dans les réponses longues ; le fix fuite mémoire est critique pour les sessions multi-agents (Anthropic a documenté des crashes à 60+ subagents simultanés).
- 🎯 **Micro-action ≤15min** : `claude --version` → si < 2.1.238, `npm update -g @anthropic-ai/claude-code` → puis `/config` → Output style → **Concise** → tester sur 1 requête.

### 2. [Shopify Checkout Extensibility — J-5 (deadline 26 août), Google Ads/Meta Pixel coupés](https://revize.app/blog/shopify-checkout-deadline-august-2026)
- 📅 Deadline dans 5 jours (26 août 2026) · 📺 Shopify officiel + communauté · 🏷 Axe 4 — Shopify
- 💡 **TL;DR** : Le 26 août, Shopify supprime automatiquement Additional Scripts, GTM containers et pixels tracking de TOUS les stores non-Plus (Basic, Shopify, Advanced). Google Ads conversion tracking, Meta Pixel, affiliate scripts et logique COD arrêtent de fonctionner sans migration préalable vers Checkout UI Extensions + Shopify Pixels.
- ⭐ **Pourquoi Ivan** : TempleTwins et PURESOLE sont probablement des stores non-Plus. Si les pixels Meta/Google passent encore par Additional Scripts → attributions publicitaires coupées dans 5 jours → campagnes qui tournent en aveugle, coût non mesuré.
- 🎯 **Micro-action ≤15min** : Shopify Admin → Settings → Checkout → si onglet "Additional Scripts" visible avec contenu → URGENT : lancer migration immédiatement. Guide complet : digitalapplied.com/blog/shopify-checkout-extensibility-deadline-august-26

### 3. [Shopify Storefront MCP cart tools → UCP Cart MCP (sunset 31 août)](https://shopify.dev/changelog/storefront-mcp-cart-tools-are-being-deprecated-in-favour-of-ucp-cart-mcp)
- 📅 Annonce June 24, sunset August 31 · 📺 Shopify officiel (developer changelog) · 🏷 Axe 5 — MCP + Axe 4 — Shopify
- 💡 **TL;DR** : Les outils MCP `get_cart` et `update_cart` du Storefront MCP Shopify sont dépréciés. Les agents IA utilisant ces outils (agents de récupération de paniers abandonnés, checkout assistant, analytics commandes) doivent migrer vers les nouveaux endpoints UCP Cart MCP sur `https://{shop}/api/ucp/mcp` avant le 31 août, en ajoutant `meta.ucp-agent.profile` dans chaque requête.
- ⭐ **Pourquoi Ivan** : Si Ivan utilise (ou prévoit) des agents Claude pour interagir avec son store Shopify via MCP — inventaire, paniers, checkout — ces agents cessent de fonctionner le 31 août sans migration.
- 🎯 **Micro-action ≤15min** : Ouvrir `.mcp.json` → chercher `get_cart` ou `update_cart` → si présent, migrer endpoint vers `/api/ucp/mcp` et ajouter le profil UCP. Guide : weaverse.io/blogs/shopify-storefront-catalog-mcp-ucp-migration-hydrogen-2026
