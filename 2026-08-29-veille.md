## 🤖 Axe 2 — Claude updates

### [Claude Code restricted mode (--restricted) — sécurité deployments contrôlés](https://code.claude.com/docs/en/whats-new) — Anthropic · Août 2026
Le flag `--restricted` retire les outils built-in qui exécutent des commandes ou du code et WebFetch, limite les outils fichiers au working directory, refuse bypassPermissions et ignore les fichiers settings utilisateur/projet. Conçu pour les environnements CI/CD sécurisés et les deployments en prod. → *Utile pour les futures pipelines automatisées PURESOLE si Claude accède à des données sensibles*

### [Claude API : mid-conversation tool changes préservent le prompt cache (Opus 4.8/5)](https://platform.claude.com/docs/en/release-notes/overview) — Anthropic · Août 2026
Il est maintenant possible d'ajouter ou retirer des outils entre les tours d'une conversation tout en préservant le prompt cache sur Claude Opus 4.8 et Opus 5. Également : le paramètre `fallbacks` supporte un mode "default" qui applique les modèles de fallback recommandés par Anthropic par catégorie de refus. → *Utile pour les agents multi-étapes avec toolsets dynamiques*
