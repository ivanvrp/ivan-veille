### 1. [Shopify Checkout MCP + Cart MCP — UCP buyer consent live](https://shopify.dev/changelog/checkout-mcp-and-cart-mcp-now-support-ucp-buyer-consent)
- 📅 Il y a 9 jours (Oct 16) · 📺 Shopify Dev Changelog officiel · 🏷 Shopify + MCP
- 💡 **TL;DR** : Checkout MCP et Cart MCP supportent maintenant le module de consentement acheteur UCP (`dev.ucp.shopping.buyer_consent`). Les agents AI qui font du checkout reçoivent un objet `buyer.consent` avec les préférences marketing (email, SMS, analytics, sale_or_sharing). Sans ce consent envoyé → Shopify applique les défauts pays (opt-out), et un SMS opt-in sans téléphone = commande bloquée (`missing_consent_data`).
- ⭐ **Pourquoi Ivan** : Si TT ou PURESOLE intègre (ou envisage) un agent Claude pour le checkout via MCP, ce consent est obligatoire pour ne pas bloquer les commandes. Aussi : toute app returns/checkout tierce qui utilise Cart MCP doit passer sur UCP version 2026-08-25 minimum.
- 🎯 **Micro-action ≤15min** : Shopify Admin → vérifier la version UCP de tes apps/agents checkout. Rechercher dans `/.well-known/ucp` de ton storefront si le consent extension est exposé. Si tu n'as pas d'agent checkout actif → sauvegarder le bookmark pour quand tu intègres Claude × Shopify.

### 2. [Meta product browsing actif par défaut le 28 octobre — 3 jours pour opt-out](https://www.relevantaudience.com/meta/meta-product-browsing-existing-ads-october-28/)
- 📅 Cette semaine · 📺 Relevant Audience / Meta notice · 🏷 E-com ads
- 💡 **TL;DR** : Le 28 octobre 2026, Meta active automatiquement "product browsing" sur TOUTES les pubs existantes. Résultat : quand quelqu'un clique sur une pub, Meta affiche d'abord une page produit hébergée sur Meta (avec suggestions personnalisées) avant de renvoyer vers le site. Meta cite +3% conversions (test sur ~117k annonceurs, 6-21 août 2026), mais l'opt-out est disponible avant le 28.
- ⭐ **Pourquoi Ivan** : TT streetwear et PURESOLE ont des campagnes Meta actives. Sans opt-out avant le 28 oct : les visiteurs voient une page Meta intermédiaire → attribution cassée, pixel moins précis, CRO du landing page court-circuité. Décision consciente : activer pour tester le +3% conversions OU opt-out pour garder le contrôle de l'expérience.
- 🎯 **Micro-action ≤15min** : Meta Ads Manager → Advantage+ Creative settings → chercher "Product browsing" → opt-out avant le 28 oct si tu veux maintenir le contrôle. Sinon : activer sur 1 adset test pour mesurer ROAS avant le déploiement total.

### 3. [MCP reference servers v2.0.0 — Node.js 24 requis pour TypeScript](https://www.remio.ai/post/mcp-servers-v2-0-0-adds-modern-protocol-support-while-keeping-legacy-clients)
- 📅 Il y a 6 jours (Oct 19) · 📺 Remio.ai / GitHub MCP officiel · 🏷 MCPs
- 💡 **TL;DR** : La suite officielle de serveurs MCP de référence (filesystem, git, postgres, puppeteer, etc.) passe en v2.0.0. Nouveaux features protocol moderne activés, mais les serveurs TypeScript **requièrent maintenant Node.js 24**. Les clients legacy restent supportés. Plusieurs corrections de stabilité et de sécurité incluses.
- ⭐ **Pourquoi Ivan** : Si tu utilises des MCP servers officiels dans Claude Code (ex. filesystem MCP pour naviguer les fichiers ivan-veille, git MCP, etc.) → vérifier la version Node.js. La plupart des setups macOS/Homebrew récents sont déjà sur Node 22+. Update Node 24 = accès aux nouveaux features + fixes sécurité.
- 🎯 **Micro-action ≤15min** : Dans ton terminal : `node --version`. Si < 24 : `brew upgrade node` ou `nvm install 24 && nvm use 24`. Puis `npm update -g` pour mettre à jour les MCP servers globaux. Si tu n'as pas encore les MCP servers officiels : `npm install -g @modelcontextprotocol/server-filesystem`.
