## 🔥 Top 3 (à actionner cette semaine)

### 1. [Notion MCP officiel hébergé — 1 commande, 0 API token](https://developers.notion.com/guides/mcp/get-started-with-mcp)
- 📅 Hier (14 oct) · 📺 Notion officiel · 🏷 🔌 MCP
- 💡 **TL;DR** : Notion lance son serveur MCP hébergé officiel : `claude mcp add --transport http notion https://mcp.notion.com/mcp` + OAuth — Claude Code peut désormais chercher dans ton workspace, lire pages/databases en Markdown, créer et mettre à jour des pages, sans aucun token API à gérer.
- ⭐ **Pourquoi Ivan** : Si tu gères ton backlog TT/PURESOLE dans Notion, Claude Code peut maintenant lire ta base produits, créer des briefs creatifs ou mettre à jour tes checklists directement depuis le terminal — zéro copier-coller.
- 🎯 **Micro-action ≤15min** : `claude mcp add --transport http --scope user notion https://mcp.notion.com/mcp` → /mcp dans Claude Code → OAuth Notion → test : "cherche mes pages produits PURESOLE".

### 2. [Shopify API 2025-10 se retire DEMAIN 16 oct — tracking à vérifier](https://shopify.dev/changelog/release-notes/2026-10)
- 📅 Urgent (deadline 16 oct 2026) · 📺 Shopify officiel · 🏷 🛒 Shopify/CRO
- 💡 **TL;DR** : La version API 2025-10 est désactivée le 16 octobre. En parallèle, depuis le 1er oct les mutations `scriptTagCreate`/`scriptTagUpdate` retournent des erreurs sur toutes versions — les stores avec tracking legacy sont en partie aveugles jusqu'à migration vers Web Pixels API.
- ⭐ **Pourquoi Ivan** : Un pixel non migré = données Meta/TikTok incorrectes, ROAS faussé, scaling sur mauvaises bases. Pour TT et PURESOLE, vérifier en urgence avant toute campagne Q4.
- 🎯 **Micro-action ≤15min** : Shopify Admin → Paramètres → Pixels & Canaux de vente. Si tu vois un pixel legacy (non Web Pixels), ouvrir le guide de migration et planifier avant le 23 oct (deadline retour shipping tax ensuite).

### 3. [Ad Creative Benchmarks 2026 — CTR, Hook Rate & Durée par format (benly.ai)](https://benly.ai/learn/ad-creative/ad-creative-benchmarks-2026)
- 📅 Cette semaine · 📺 Benly (source benchmark créatif) · 🏷 📊 E-com ads
- 💡 **TL;DR** : UGC-style bat le polished studio sur Meta pour hook rate et CTR sur le mid-market ; le polished gagne sur brand recall et tickets élevés. Durées optimales : 15-30s sur Meta, <15s sur TikTok. Budget recommandé pour test créatif : 15-20% du budget hebdo, 3-5 variants avec hooks distincts (pas des variantes légères).
- ⭐ **Pourquoi Ivan** : Pour TempleTwins streetwear sur TikTok, les hooks UGC-style performent mieux — à confirmer avec 3 variants distincts sur une même audience avant de scaler. Pour PURESOLE, le ratio 15-20% test budget donne un cadre de test systématique.
- 🎯 **Micro-action ≤15min** : Dans ton Ads Manager Meta, identifier ta campagne la plus active, dupliquer l'ad set, créer 3 variants UGC avec hooks distincts (problem/hook/solution, testimonial, "POV tu découvres") — même budget, même audience, laisser tourner 72h.
