### 1. [Claude Code — fiabilité des agents en arrière-plan + hooks exact-match](https://code.claude.com/docs/en/whats-new)
- 📅 fin juin 2026 · 📺 Anthropic (docs officielles) · 🏷 Claude updates
- 💡 **TL;DR** : correctifs ciblés — les jobs en arrière-plan qui *disparaissaient* de `claude agents` (ou perdaient leurs données quand écrits par une version plus récente) sont fixés ; le daemon d'agents qui restait injoignable au démarrage est réparé ; et les **hook matchers à identifiant composé** (`code-reviewer`, `mcp__brave-search`…) font enfin du **match exact** au lieu de matcher une sous-chaîne.
- ⭐ **Pourquoi Ivan** : tu fais tourner des **routines cron** (veille-360, veille-claude) + des **hooks** (backup auto thème Shopify). Le fix background-agent = tes veilles planifiées plus fiables ; le fix hook exact-match = plus de déclenchements parasites si deux hooks ont des noms proches.
- 🎯 **Micro-action ≤15min** : `claude` → vérifie ta version (`/status`) et update si besoin ; re-checke que tes 2 routines veille sont bien listées dans `claude agents` après le `/login` d'aujourd'hui.

### 2. [Shopify — les cart tools du Storefront MCP dépréciés au profit d'UCP Cart MCP](https://changelog.shopify.com/posts)
- 📅 24 juin 2026 · 📺 shopify.dev changelog (officiel) · 🏷 Shopify
- 💡 **TL;DR** : `get_cart` et `update_cart` du Storefront MCP sont **dépréciés** → migrer vers **UCP Cart MCP** (nouvelle couche panier agentique de Shopify, alignée sur le Checkout Kit pour les parcours d'achat pilotés par IA).
- ⭐ **Pourquoi Ivan** : veravie tourne sur Shopify et tu pilotes le store via MCP. Si un jour tu branches un parcours panier/checkout agentique (cart drawer, achat assisté), c'est la nouvelle brique — et ça signale la direction « checkout piloté par agent » de Shopify.
- 🎯 **Micro-action ≤15min** : rien d'urgent (tu n'utilises pas ces tools aujourd'hui) → juste noter : ne PAS bâtir de nouveau flow sur `get_cart`/`update_cart`, partir sur UCP Cart MCP.

### 3. [Meta ads 2026 — tester des PERSONAS, pas juste des hooks (et varier le format)](https://motionapp.com/blog/how-to-build-a-high-volume-ad-production-system-for-meta-and-tiktok-in-2026)
- 📅 fin juin 2026 · 📺 Motion / Barhamm · 🏷 E-com ads
- 💡 **TL;DR** : le levier 2026 n'est plus « 1 hook large » mais **plusieurs avatars acheteurs** dans un même ad set (sceptique / chercheuse de deal / pressée / curieuse), ET **changer le FORMAT** (UGC, statique, founder-video, screenshot) — pas seulement la 1ère phrase.
- ⭐ **Pourquoi Ivan** : tes créas veravie tournent autour d'un angle (trahison médicale / ménopause). Décliner par **persona × format** = plus de chances de trouver le combo gagnant sans repartir de zéro.
- 🎯 **Micro-action ≤15min** : lister 3 personas veravie (femme sceptique / déjà-tout-essayé / veut une solution simple) → écrire 1 hook par persona → les router sur 3 formats différents (tweet, iMessage, photo) que t'as déjà.
