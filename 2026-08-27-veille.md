### 1. [Shopify Storefront MCP → UCP Cart MCP — deadline DANS 4 JOURS (31 août)](https://shopify.dev/changelog/storefront-mcp-cart-tools-are-being-deprecated-in-favour-of-ucp-cart-mcp)
- 📅 Annoncé août 2026 · deadline **31 août** · 📺 Shopify Developer Changelog (officiel) · 🏷 Axe 4+5 — Shopify / MCP
- 💡 **TL;DR** : Les outils `get_cart` et `update_cart` du Storefront MCP endpoint `/api/mcp` **arrêtent de fonctionner le 31 août 2026** — pas juste dépréciés, ils cessent de répondre. La migration se fait vers `/api/ucp/mcp` (UCP Cart MCP). Attention : ce n'est pas un simple changement d'URL — chaque requête doit porter un profil `ucp-agent` dans un objet `meta`, `cancel_cart` exige une clé d'idempotence, et `update_cart` attend maintenant le tableau complet des line items (plus de mises à jour partielles).
- ⭐ **Pourquoi Ivan** : Toute app Hydrogen, agent IA ou intégration custom qui appelle `/api/mcp` pour la gestion du panier (recommandations produit, add-to-cart automatisé, agents de checkout) casse dans 4 jours. Même si PURESOLE ou TempleTwins n'ont pas encore d'agent IA panier actif, c'est le bon moment de comprendre le nouveau paradigme UCP pour bâtir dessus plutôt que sur l'ancienne Storefront API.
- 🎯 **Micro-action ≤15min** : Chercher `"/api/mcp"` et `"storefront mcp"` dans le code du store. Si trouvé → suivre le guide de migration [weaverse.io](https://weaverse.io/blogs/shopify-storefront-catalog-mcp-ucp-migration-hydrogen-2026) (le plus complet pour Hydrogen). Sinon → lire l'article [li.solutions](https://li.solutions/blog/shopify-ucp-agent-commerce/) sur le nouveau paradigme e-com agentique avec UCP.
