### 1. [Workload Identity Federation GA — fin des clés API statiques Claude](https://claude.com/blog/workload-identity-federation)
- 📅 6 jours (17 juin 2026) · 📺 Anthropic officiel · 🏷 Claude updates
- 💡 **TL;DR** : Claude API accepte désormais AWS IAM, GitHub OIDC, Google Cloud, Okta et Kubernetes tokens courts pour l'authentification — les workloads agents, routines cron et CI/CD n'ont plus besoin de stocker des ANTHROPIC_API_KEY statiques dans les secrets.
- ⭐ **Pourquoi Ivan** : La routine veille-360 et les agents Claude Code sur GitHub Actions stockent actuellement un PAT Anthropic dans les GitHub Secrets. Avec WIF, ce secret est remplacé par un token OIDC éphémère GitHub → surface d'attaque réduite à zéro, conforme DevSecOps.
- 🎯 **Micro-action ≤15min** : Dans le workflow GitHub Actions de la routine → ajouter `permissions: id-token: write` → suivre le guide WIF Anthropic pour GitHub OIDC (platform.claude.com/docs/en/manage-claude/workload-identity-federation) → tester en dry-run.

- 🎯 **Micro-action ≤15min** : Shopify Admin → Collections → choisir la collection avec le plus de trafic → activer "AI Sort" → lancer un Rollout 50/50 thème actuel vs prochaine version.

### 3. [Enterprise-Managed Auth MCP — Okta provisionne 7 connecteurs sans friction](https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/)
