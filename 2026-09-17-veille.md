### 3. [context-mode — MCP qui réduit le contexte de 98% pour les agents IA (23K★, +1 612/semaine)](https://github.com/mksglu/context-mode)
- 📅 Trending cette semaine · 📺 GitHub Trending TypeScript · 🏷 MCPs
- 💡 **TL;DR** : Serveur MCP qui optimise la fenêtre de contexte des agents de code IA : sandboxe les outputs d'outils (315 KB → 5,4 KB, soit -98%), persiste la mémoire de session (edits, git ops, tâches, erreurs) dans SQLite (survit à la compaction), indexe du markdown avec FTS5+BM25, bloque les commandes dangereuses via hooks. - ⭐ **Pourquoi Ivan** : Les sessions longues Claude Code pour TT/PURESOLE (refacto Shopify, generation de produits, veille automatique) atteignent souvent les limites de contexte. context-mode compresse les résultats d'outils de 98% → les sessions peuvent durer beaucoup plus longtemps sans compacter ou perdre de l'état. La persistance SQLite signifie qu'un agent peut reprendre exactement où il était.
- 🎯 **Micro-action ≤15min** : `npm install -g @mksglu/context-mode` puis ajouter dans `~/.claude/settings.json` sous `mcpServers` : `{ "context-mode": { "command": "context-mode" } }`. Tester sur une session type "refacto Dawn theme" pour mesurer la réduction de tokens.
