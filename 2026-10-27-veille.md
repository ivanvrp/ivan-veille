### 1. [Meta Product Browsing ON par défaut DEMAIN — opt-out avant le 28 oct](https://www.relevantaudience.com/meta/meta-product-browsing-existing-ads-october-28/)
- 📅 Annonce Oct 14, activation DEMAIN (Oct 28) · 📺 Meta / Relevant Audience · 🏷 E-com ads
- 💡 **TL;DR** : À partir du 28 octobre, Meta active automatiquement "Product Browsing" sur toutes tes publicités actives sur Facebook et Instagram. Résultat : un tap sur ta pub ouvre une page in-app Meta (avec suggestions de produits personnalisés) avant de renvoyer vers ton site. Meta a testé sur 117 700 annonceurs et revendique +3% conversions — mais sans définir la métrique ni le coût. L'opt-out reste ouvert jusqu'à demain via un bouton dans l'avis reçu, ou dans Advantage+ Creative & Destination settings (modifiable à tout moment).
- ⭐ **Pourquoi Ivan** : TT et PURESOLE ont des ads actives sur Meta. Cette "page produit in-app" peut interrompre le funnel vers ton site Shopify, brouiller l'attribution et court-circuiter tes landing pages custom. À tester sur 1 campagne en A/B avant de laisser Meta décider pour toi.
- 🎯 **Micro-action ≤15min** : Meta Ads Manager → Paramètres de compte ou via le bouton dans la notification Meta reçue → "Advantage+ Creative" → "Product Browsing" → **désactiver sur toutes les campagnes actives avant le 28 oct minuit**. Garder ON sur une seule campagne test pour mesurer l'impact.

### 2. [Claude Code v2.1.311 — `ultrathink` passe en effort xhigh (Oct 26)](https://aimaker.substack.com/p/claude-code-updates-october-2026)
- 📅 Hier (Oct 26) · 📺 Anthropic changelog / AImaker · 🏷 Claude updates
- 💡 **TL;DR** : Claude Code v2.1.311 (Oct 26) change le comportement de `ultrathink` : il passe désormais en effort `xhigh` sur les modèles compatibles au lieu de `max`. Aussi : options `--hold-idle-file` et `--max-hold-min` pour le `self-hosted-runner` (contrôle précis des sessions cloud idle), et coloration syntaxique des blocs de code dans VSCode. Versions précédentes la semaine : v2.1.307 ajoute `/claude-api api-version` pour migrer vers l'API `2026-10-21` + OpenTelemetry `claude_code.safety_event`.
- ⭐ **Pourquoi Ivan** : Si tu utilises `ultrathink` dans tes prompts de veille ou de génération de briefs créa (TempleTwins), tu consommeras moins de tokens qu'avant (xhigh < max). Impact direct sur tes coûts API. Le `self-hosted-runner` idle contrôle les sessions cloud longues comme la veille automatique.
- 🎯 **Micro-action ≤15min** : `claude --version` → vérifier que tu es en 2.1.311. Dans tes prompts lourds (génération de brief, veille 360), remplacer `think harder` par `ultrathink` si ce n'est pas déjà le cas — tu profites du nouveau plafond xhigh à coût optimisé.

### 3. [Claude Code MCP Tasks + Elicitations — jobs durables avec pause consent (Oct 22/23)](https://upstash.com/blog/claude-code-mcp-tasks)
- 📅 Annoncé Oct 22, disponible dès v2.1.304+ · 📺 Anthropic / Upstash · 🏷 MCPs
- 💡 **TL;DR** : Claude Code supporte désormais les MCP Tasks et Elicitations (protocole 2026-07-28, v2.1.304+). Un outil MCP peut maintenant lancer une tâche longue (scrape, génération, déploiement), retourner immédiatement un handle, et l'utilisateur reprend le résultat plus tard sans garder la session ouverte. Les "Elicitations" permettent au serveur MCP de poser une question en milieu de tâche (formulaire dans le terminal). Limité pour l'instant au CLI interactif, Agent SDK et GitHub Actions — VS Code et desktop app suivront.
- ⭐ **Pourquoi Ivan** : La routine veille-360 tourne déjà en RemoteTrigger. Avec MCP Tasks, un futur serveur MCP de veille pourrait s'exécuter en background (Upstash, Cloudflare Worker), poser une question si besoin (ex: "couvrir l'annonce Shopify ou skip?") et livrer le digest complet sans maintenir une session active. Réduction drastique des coûts cloud session.
- 🎯 **Micro-action ≤15min** : `claude --version` ≥ 2.1.304. Tester avec le MCP Upstash (Redis) : `claude mcp add --transport http https://mcp.upstash.io` et lancer une tâche longue pour voir les Elicitations en action. Docs officielles : upstash.com/blog/claude-code-mcp-tasks.
