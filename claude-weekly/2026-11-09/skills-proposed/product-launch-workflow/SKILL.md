## Ce que fait ce skill

Encapsule un workflow complet de lancement d'un nouveau produit dropshipping pour PURESOLE et TempleTwins. Orchestre les étapes séquentielles : research → copy → contenu visuel → social → dev brief → suivi.

## Déclencheur

Quand Ivan dit : "Lance un nouveau produit", "Je veux ajouter ce produit", ou inclut une URL fournisseur.

## Workflow

1. **Recherche marché** : Analyse concurrentielle rapide (prix, positionnement, reviews)
2. **Description produit** : Génère une fiche produit Shopify optimisée SEO (titre, description, bullet points, meta)
3. **Brief créatif** : Propose 3 angles visuels pour les photos/vidéos (moodboard en mots)
4. **Social media kit** : 1 caption Instagram + 1 tweet "build-in-public" + 1 TikTok hook
5. **Dev brief** (si personnalisation Shopify nécessaire) : Spécifications techniques au format markdown
6. **Task list** : Génère une checklist Notion/Markdown des tâches de suivi avec deadlines suggérées

## Instructions pour Claude

Lorsque ce skill est invoqué :
- Demander : nom du produit, niche cible (TempleTwins streetwear / PURESOLE dropship), prix de vente cible, URL fournisseur si disponible
- Produire les 6 livrables ci-dessus dans l'ordre
- Adapter le ton : streetwear (TempleTwins = jeune, urban, authentique) vs dropship (PURESOLE = clean, bénéfice-orienté)
- Ne PAS décider du prix final — le proposer comme fourchette

## Références
- Format fiche Shopify : titre <60 chars, description 150-300 mots, 5 bullet points
- SEO : inclure 2-3 mots-clés longue traîne dans la description
- Pas de jargon IA dans le contenu final
