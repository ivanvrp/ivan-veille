## Ce que fait ce skill

Génère des descriptions de produits claires, engageantes et optimisées SEO pour les fiches Shopify de TempleTwins et PURESOLE. Adapte le ton à chaque marque.

## Instructions pour Claude

Lorsque ce skill est invoqué avec les infos produit :

### Entrées attendues
- Nom du produit
- Marque cible (TempleTwins streetwear / PURESOLE dropship)
- 3-5 caractéristiques clés
- Prix de vente
- Audience cible

### Livrables

**TempleTwins (ton : urban, authentique, storytelling)**
- Titre Shopify : max 60 chars, inclure matière + style
- Description : 180-250 mots, storytelling de la pièce, lifestyle, pas de jargon
- Bullet points : 5 points, bénéfices concrets (matière, coupe, occasion)
- Meta description : 155 chars max pour SEO
- Tags Shopify suggérés : 8-10 tags pertinents

**PURESOLE (ton : clean, bénéfice-orienté, rassurant)**
- Titre : max 60 chars, bénéfice principal + matière
- Description : 150-200 mots, focus bénéfices, preuves sociales si dispo
- Bullet points : 5 points (utilité, qualité, livraison, retour, garantie)
- Meta description : 155 chars max

### Règles SEO
- 2-3 mots-clés longue traîne intégrés naturellement
- Premier paragraphe contient le mot-clé principal
- Pas de répétition du titre dans la meta description

## Score utilité estimé : 9/10
