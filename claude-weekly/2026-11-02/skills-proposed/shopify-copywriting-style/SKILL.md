# Shopify Copywriting Style — TempleTwins & PURESOLE

## Contexte
Ivan Vasseur = fondateur TempleTwins (streetwear Shopify) + PURESOLE (dropship sneakers).
Style de marque : authentique, urbain, storytelling produit, conversion-first.

## Utilisation
Invoque ce skill pour générer descriptions produits, emails Klaviyo, landing pages, textes publicités Meta.

## Instructions
1. Identifie le produit (nom, catégorie, points clés)
2. Détermine la marque cible (TempleTwins = streetwear culturel / PURESOLE = sneakers lifestyle)
3. Génère en fr + en si demandé
4. Structure : hook accrocheur → description sensorielle → bénéfices → CTA conversion

## Format output
```
[FR] Titre : {titre produit accrocheur}
Description courte (< 160 chars, SEO) : {...}
Description longue (< 500 chars) : {...}
CTA : {...}

[EN] (si demandé)
Title : {...}
...
```

## Notes
- Éviter le jargon générique "qualité premium"
- Références culturelles streetwear légitimes (pas forcées)
- Variants couleur/taille intégrés naturellement dans le texte
