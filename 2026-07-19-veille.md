### 3. [Shopify API 2026-07 stable — nouveau modèle Collections (fin du split smart/custom)](https://shopify.dev/changelog/new-collection-model-and-apis-now-available)
- 📅 1er juillet 2026 · 📺 Shopify Engineering / shopify.dev changelog · 🏷 Axe 4 — Shopify
- 💡 **TL;DR** : Les collections Shopify ne sont plus "smart" ou "custom" — chaque collection est construite depuis une ou plusieurs **sources composables** (règles de produits, variantes ciblées, références à d'autres collections, sources partagées d'apps). `ruleSet` est déprécié. Les API antérieures à 2026-07 ne représentent pas les collections du nouveau modèle — migration requise pour accéder aux nouvelles collections.
- ⭐ **Pourquoi Ivan** : Toute app de merchandising, de filtres ou d'automatisation de collections sur TempleTwins ou PURESOLE qui utilise l'API GraphQL Admin doit migrer vers 2026-07. Les collections créées avec des apps modernes (ex. taggées par agent IA) utilisent déjà le nouveau modèle et deviennent invisibles sur les apps en 2026-04 ou antérieures.
- 🎯 **Micro-action ≤15min** : Admin Shopify → Apps → lister les apps de gestion de collections → vérifier dans leur documentation si elles supportent l'API 2026-07 → ouvrir un ticket support pour celles qui ne le mentionnent pas.
