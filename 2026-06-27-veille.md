### 3. [`claude mcp login <name>` — Authentification MCP depuis le terminal](https://code.claude.com/docs/en/whats-new/2026-w26)

- 💡 **TL;DR** : `claude mcp login <serveur>` lance le flux OAuth directement depuis le shell sans passer par le menu interactif `/mcp`. `claude mcp logout <serveur>` révoque les credentials. Disponible depuis v2.1.186.
